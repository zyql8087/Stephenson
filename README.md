本代码库实现了基于**差分进化 (DE)** 与 **Adam 梯度下降**混合优化的 Stephenson III 仿生腿尺寸综合流程。

#### 1. 核心功能文件
+ `kinematics.py`** (运动学内核)**：
    - 定义了 Stephenson III 机构的运动学正解方程。
    - 输入：8-10个结构参数（杆长、初始角等）及曲柄转角序列。
    - 输出：足端 $ (x, y) $ 坐标序列，以及用于计算传动角的内部关节角度。
+ `train_evolution.py`** (优化主逻辑)**：
    - **阶段 A**：调用 `scipy.optimize.differential_evolution` 进行全局搜索，跳出非凸空间的局部最优陷阱。
    - **阶段 B**：利用 PyTorch 的 Adam 优化器对 DE 找到的初值进行梯度精修。
    - 包含损失函数 `calculate_loss`：整合了足端轨迹误差（支撑相加权）、传动角惩罚（防止卡死）和膝关节防反弯约束。
+ `data_loader.py`** (数据预处理)**：
    - 负责从 Excel 或 CSV 中读取生物步态数据。
    - 利用样条插值或线性插值将目标步态统一重采样为 100 个相位点，确保与模型输出对齐。

#### 2. 工具与脚本
+ `main.py`** (程序入口)**：
    - 一键启动脚本，依次调用数据加载、全局搜索、局部微调，并最终触发可视化。
+ `data_utils.py`** / **`generate_target_excel.py`：
    - 用于生成或转换目标轨迹文件的辅助工具。
+ `target_gait.csv`：
    - 存储目标生物步态轨迹的标准输入文件。

---

###  整体代码运行流程
1. **数据初始化**：`main.py` 启动，通过 `data_loader.py` 加载目标轨迹。
2. **全局寻优 (DE)**：在 `train_evolution.py` 中，差分进化算法在设定的杆长边界内大范围撒网，寻找不触发“卡死惩罚”且轨迹大致匹配的初值。
3. **梯度精雕 (Adam)**：将 DE 找到的最佳参数注入 PyTorch 模型，Adam 优化器以微小的步长（Learning Rate）顺着梯度下降，优化轨迹细节。
4. **物理约束检查**：在每轮迭代中，`enforce_physical_bounds` 函数会强制将曲柄长度等关键尺寸锁定在可制造范围内。
5. **结果输出**：运行结束后，程序会自动弹出**轨迹对比图**与 **Loss 收敛曲线图**，并打印出最终的最优杆长参数表。
